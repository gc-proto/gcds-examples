# Page templates
Page templates are pre-built pages that combine GC Design System components for common presentations. They’re fully responsive for multi-device use. Their page structures support a predictable, recognizable, and accessible user experience.

Visit our [documentation website](https://design-system.alpha.canada.ca/en/page-templates/) for more information.

## File types used in this folder

- **`.njk` (Nunjucks) files:** Used to build the navigation and gallery pages for the example site.
- **`.html` files:** Used to create the actual GC Design System (GCDS) page templates. These are the files that end-users will copy and adapt.
- **`.md` (Markdown) files:** Used for documentation, such as explaining the contribution model for GCDS templates.

# Modèles de page
Les modèles de page sont des pages préconstruites qui agencent des composants de Système de design GC pour créer des mises en page courantes. Ces pages sont entièrement réactives et peuvent donc être utilisées sur tout appareil. La structure des pages favorise une expérience utilisateur prévisible, reconnaissable et accessible.

Visitez notre [site de documentation](https://systeme-design.alpha.canada.ca/fr/modeles-de-page/) pour plus d'informations.

## Types de fichiers utilisés dans ce dossier

- **Fichiers `.njk` (Nunjucks) :** Utilisés pour construire les pages de navigation et de galerie pour le site d'exemples.
- **Fichiers `.html` :** Utilisés pour créer les modèles de page réels du Système de design du GC (SDGC). Ce sont les fichiers que les utilisateurs finaux copieront et adapteront.
- **Fichiers `.md` (Markdown) :** Utilisés pour la documentation, comme l'explication du modèle de contribution pour les modèles SDGC.
